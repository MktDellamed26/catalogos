Como criar o token (uma vez por administrador)
  1. No GitHub, entre em Settings → Developer settings → Personal access tokens → Fine-grained tokens e clique em Generate new token.
  2. Em Repository access, escolha Only select repositories e marque só o repositório da Prateleira.
  3. Em Permissions → Repository permissions → Contents, escolha Read and write.
  4. Gere o token, copie e cole aqui. Ele fica guardado neste computador, protegido pela senha mestra.

Cada alteração é publicada na hora. O site atualiza em cerca de 1 minuto.
