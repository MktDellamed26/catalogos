Como criar o token (uma vez por administrador)
  1. No GitHub, clique na sua foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Em Repository access, escolha Only select repositories e marque só o repositório da Prateleira.
  3. Em Permissions → Repository permissions → Contents, escolha Read and write.
  4. Gere o token, copie e cole aqui. Ele fica guardado neste computador, protegido pela senha mestra. Nunca envie o token por e-mail ou chat.

Cada alteração é publicada na hora. O site atualiza em 1 a 3 minutos.
